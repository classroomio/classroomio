You're here to build something on top of ClassroomIO, not run an academy in it: calling the API
from your own app, connecting an agent client or an SSO-style handoff, running the stack on your
own infrastructure, or working on ClassroomIO's own code.

<CodeGroup>

```bash cURL
curl https://api.classroomio.com/public-api/v1/courses \
  -H "Authorization: Bearer cio_api_your_key_here"
```

```js JavaScript
const res = await fetch('https://api.classroomio.com/public-api/v1/courses', {
  headers: { Authorization: 'Bearer cio_api_your_key_here' }
});
const { data } = await res.json();
```

</CodeGroup>

Full endpoint reference, request/response schemas, and how to get a key: [API](/api).
