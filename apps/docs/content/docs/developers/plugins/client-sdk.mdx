title: Client SDK Reference

The browser SDK runs inside a sandboxed plugin iframe. It communicates with the ClassroomIO host
over a private `MessageChannel`; plugin code does not receive ClassroomIO cookies, session tokens,
or direct database access.

## Install and initialize

```bash
npm install @classroomio/plugin-sdk
```

```typescript
import { createClassroomIOClient } from '@classroomio/plugin-sdk/client';

const client = createClassroomIOClient({ timeoutMs: 8000 });
const context = await client.context.get();
```

The default RPC timeout is 5 seconds. Requests are limited to 64 KiB and responses to 256 KiB.
Rejected calls throw `PluginBridgeError` with one of these codes: `UNAUTHORIZED`, `FORBIDDEN`,
`INVALID_PARAMS`, `RATE_LIMITED`, `TIMEOUT`, `INTERNAL_ERROR`, `NOT_FOUND`, `NOT_SUPPORTED`, or
`RESPONSE_TOO_LARGE`.

## Context and capabilities

`client.context.get()` resolves after the host handshake. The result identifies the installed
plugin, actor, organization, active surface, and optional surface resource.

```typescript
const context = await client.context.get();

console.log(context.installationId);
console.log(context.pluginId);
console.log(context.actor?.role);
console.log(context.surface?.target);
console.log(context.surface?.resource);

const grantedScopes = await client.capabilities.list();
```

`client.capabilities.list()` returns the installation's granted scopes. A declared manifest
permission is not sufficient by itself: the organization must grant it, and each host route also
checks the current actor and resource.

## Host UI and navigation

```typescript
await client.ui.toast({ message: 'Saved', variant: 'success' });
await client.ui.resize(document.documentElement.scrollHeight);
await client.ui.setDirty(true);
await client.navigation.open('/courses');
```

| Method | Behavior |
| --- | --- |
| `client.ui.toast(options)` | Shows a host snackbar. Variants are `info`, `success`, `warning`, and `error`; unsupported visual variants fall back to the host's informational style. |
| `client.ui.resize(height)` | Requests an iframe height. The host clamps it to the active surface contract. |
| `client.ui.setDirty(dirty)` | Enables or clears the browser unload warning for unsaved changes. |
| `client.navigation.open(href)` | Navigates to a host-relative path. External and protocol-relative URLs are rejected. |

The host does not expose a modal API. Build overlays inside the iframe or use a declared full-page
plugin contribution.

For content whose height changes, observe the document and send the new height:

```typescript
const observer = new ResizeObserver(() => {
  void client.ui.resize(document.documentElement.scrollHeight);
});

observer.observe(document.body);
```

## Theme synchronization

The host applies theme values to the plugin document and publishes the complete theme object.

```typescript
const theme = await client.theme.get();
console.log(theme.colorScheme);

const unsubscribe = client.theme.onChange((nextTheme) => {
  console.log(nextTheme.colorScheme, nextTheme.reducedMotion);
});
```

The SDK sets `data-theme`, `color-scheme`, and these CSS properties:

| Colors | Shape and type |
| --- | --- |
| `--cio-background` | `--cio-radius-sm` |
| `--cio-surface` | `--cio-radius-md` |
| `--cio-surface-muted` | `--cio-radius-lg` |
| `--cio-foreground` | `--cio-font-sans` |
| `--cio-foreground-muted` | `--cio-font-mono` |
| `--cio-border` | |
| `--cio-accent` | |
| `--cio-accent-foreground` | |
| `--cio-destructive` | |

Compatibility aliases are also set: `--cio-color-bg`, `--cio-color-bg-subtle`,
`--cio-color-surface`, `--cio-color-text`, `--cio-color-text-secondary`,
`--cio-color-border`, and `--cio-color-primary`.

```css
body {
  background: var(--cio-background);
  color: var(--cio-foreground);
  font-family: var(--cio-font-sans);
}

.card {
  background: var(--cio-surface);
  border: 1px solid var(--cio-border);
  border-radius: var(--cio-radius-md);
}
```

## Browser preferences

Preferences are small browser-local values keyed by profile, installation, namespace, and key.
They are not synchronized across browsers and are not part of persistent plugin storage.

```typescript
await client.preferences.set('collapsed', true, 'sidebar');
const collapsed = await client.preferences.get<boolean>('collapsed', 'sidebar');
await client.preferences.delete('collapsed', 'sidebar');
```

## Hosted plugin storage

Plugin data is stored by ClassroomIO and isolated to the installed plugin. A namespace and scope
must be declared in `storage.documents` in the manifest. Reads require `plugin.storage:read`; writes
and deletes require `plugin.storage:write`.

Supported scopes are `organization`, `user`, and `resource`. Resource storage uses the active
surface resource. Organization and resource writes are limited to organization admins and tutors.

```typescript
const current = await client.storage.getRecord<{ enabled: boolean }>('settings', 'configuration');

const saved = await client.storage.set(
  'settings',
  { enabled: true },
  'configuration',
  'organization',
  { schemaVersion: 1, expectedVersion: current?.version }
);

const page = await client.storage.list('configuration', 'organization', { limit: 25 });
await client.storage.delete('settings', 'configuration', 'organization');
```

`get()` returns only the value. `getRecord()` also returns `version`, `schemaVersion`, and
`updatedAt`. `expectedVersion` provides compare-and-set protection; omit it only when overwriting
the latest value is acceptable.

## Typed hosted data

These methods call ClassroomIO through the host. The plugin never manages a separate backend or
receives a bearer token.

| Namespace and method | Required scope |
| --- | --- |
| `identity.getCurrent()` | `identity.profile:read` |
| `organization.getProfile()` | `organization.profile:read` |
| `courses.list(options)`, `courses.get(id)` | `course.metadata:read` |
| `courses.getStructure(id)` | `course.content:read` |
| `lessons.list({ courseId, cursor?, limit? })`, `lessons.get(id)` | `lesson.metadata:read` |
| `lessons.getContent(id)` | `lesson.content:read` |
| `exercises.list({ courseId, lessonId?, cursor?, limit? })`, `exercises.get(id)` | `exercise.metadata:read` |
| `progress.getCurrent({ type, id })` | `learner.progress:read` |
| `progress.setCompletion(lessonId, isComplete)` | `learner.progress:write` |
| `certificates.list(options)`, `certificates.get(id)` | `certificate.issued:read` |
| `certificateTemplates.list()`, `certificateTemplates.getApplied(courseId)` | `certificate.template:read` |
| `certificateTemplates.apply(payload)` | `certificate.template:write` and the `certificate.templates` surface |

List methods return `{ items, nextCursor }`. Access remains constrained to the current
organization, actor role, enrollments, and relevant course or lesson.

`landingTemplates.preview(templateId)` and `landingTemplates.select(templateId)` are available only
in the landing-template picker surface. They dispatch typed actions to the landing-page editor;
they are not general data APIs.

## Public landing renderer

The public landing page uses a separate, smaller bridge because it runs outside an authenticated
dashboard surface.

```typescript
import { createPublicLandingRendererClient } from '@classroomio/plugin-sdk/public-landing';

const renderer = createPublicLandingRendererClient();
const context = await renderer.getContext();

renderer.onViewModelChange((viewModel) => render(viewModel));
renderer.resize(document.documentElement.scrollHeight);
renderer.navigate('/courses/example');
renderer.requestAuthentication();
```

The renderer receives only the version-1 public landing view model, theme, and authentication
state. It can request resize, sanitized navigation, or authentication; it does not receive the
authenticated hosted-data client.

Call `client.destroy()` or `renderer.destroy()` when tearing down a long-lived integration.
