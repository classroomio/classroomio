---
title: Manifest Reference (plugin.json)
description: Specification for the plugin.json manifest defining identity, permissions, slots, entrypoints, and network access.
---

Every plugin must have a `plugin.json` manifest file located in its root directory. The manifest declares the plugin's identity, requested permissions, hosted UI contributions, entrypoints, network domains, settings, storage documents, and data policy. Plugin-owned backends are not part of the hosted contract.

ClassroomIO validates the manifest during `npm run pack` (the scaffolded alias for `cio-plugin build`) and at installation time using strict Zod validation schemas.

---

## Full Annotated Example

```json
{
  "manifestVersion": 1,
  "id": "com.example.ai-assistant",
  "name": "AI Course Assistant",
  "version": "1.0.0",
  "publisher": "classroomio",
  "description": "Interactive AI tutoring and exercise assistance for students",
  "engines": {
    "classroomio": ">=2.0.0",
    "pluginApi": "2026-10-08"
  },
  "icon": {
    "resource": "dist/icon.svg"
  },
  "runtime": {
    "ui": {
      "entrypoints": {
        "chatWidget": "dist/chat.html",
        "settingsPage": "dist/settings.html"
      }
    }
  },
  "contributes": {
    "slots": [
      {
        "id": "lesson-chat",
        "target": "lesson.after",
        "entrypoint": "chatWidget",
        "title": "Ask AI Tutor"
      }
    ],
    "pages": [
      {
        "id": "assistant-settings",
        "entrypoint": "settingsPage",
        "title": "AI Assistant Configuration"
      }
    ],
    "navigation": [
      {
        "id": "nav-settings",
        "title": "AI Assistant",
        "location": "organization.navigation",
        "page": "assistant-settings",
        "visibility": "admin"
      }
    ]
  },
  "permissions": {
    "required": [
      "course.metadata:read",
      "lesson.metadata:read",
      "plugin.storage:read",
      "plugin.storage:write"
    ]
  },
  "networkAccess": {
    "allowedDomains": [
      "https://api.my-plugin.com",
      "https://api.openai.com"
    ]
  },
  "dataPolicy": {
    "storesCustomerData": true,
    "retentionAfterUninstallDays": 30,
    "privacyPolicyUrl": "https://example.com/privacy"
  },
  "storage": {
    "documents": [
      {
        "namespace": "assistant-settings",
        "scope": "organization",
        "schemaVersion": 1,
        "schema": {
          "type": "object",
          "properties": {
            "enabled": { "type": "boolean" }
          },
          "required": ["enabled"],
          "additionalProperties": false
        }
      }
    ]
  }
}
```

---

## Top-Level Fields

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `manifestVersion` | `1` | **Yes** | Version of the ClassroomIO manifest format. |
| `id` | `string` | **Yes** | Unique reverse-DNS identifier (e.g. `com.company.plugin-name`). Must match `^[a-z0-9]+(\.[a-z0-9_-]+)+$`. |
| `name` | `string` | **Yes** | Human-readable name of the plugin displayed in the marketplace. |
| `version` | `string` | **Yes** | Semantic version string (e.g. `1.0.0`). Once published, a version's artifact is immutable. |
| `publisher` | `string` | **Yes** | Registered publisher handle or domain. |
| `description` | `string` | **Yes** | Marketplace and catalog explanation of what the plugin does; 5–500 characters. |
| `slug` | `string` | No | Lowercase kebab-case URL/catalog identifier. If omitted, the host derives one from `id`. |
| `icon` | `object` | No | `resource` pointing to a packaged SVG, PNG, JPEG, or WebP asset. |
| `license` | `string` | No | License identifier or short license label shown to reviewers/users. |
| `homepage` | `string` | No | HTTPS page for the plugin or publisher. |
| `repository` | `string` | No | HTTPS source repository URL. |
| `engines` | `object` | **Yes** | Compatibility ranges for ClassroomIO and the Plugin API. |
| `runtime` | `object` | No | UI entrypoints declaration. |
| `contributes` | `object` | No | Mounting slots, full pages, actions, and navigation items. |
| `permissions` | `object` | No | Scopes required or optionally requested by the plugin. |
| `networkAccess`| `object` | No | Whitelisted domains for browser Content Security Policy (CSP). |
| `dataPolicy` | `object` | **Yes** | Customer-data handling and uninstall retention declaration. |
| `settings` | `object` | No | Optional JSON schema for plugin settings managed by the host/plugin UI. |
| `storage` | `object` | No | Namespaced organization, user, or resource documents with a schema and schema version. |
| `extensions` | `object` | No | Reserved extension metadata for forward-compatible host integrations. |

## Identity and compatibility fields

These fields are required because the host must identify the package before it can install or
review it.

| Field | What the value means | Why it is necessary |
| --- | --- | --- |
| `$schema` | Optional URL metadata. | The current CLI and host do not load it; they validate with the shipped Zod contract. No JSON Schema file is bundled with the SDK. |
| `manifestVersion` | Manifest format version. Currently `1`. | Lets the host reject an unknown format instead of guessing. |
| `id` | Globally unique reverse-domain identifier such as `com.example.reading-timer`. | Prevents collisions and establishes publisher namespace ownership. `com.classroomio.*` is reserved for ClassroomIO. |
| `slug` | Optional lowercase kebab-case display/catalog identifier. | Produces stable human-readable URLs without changing the immutable plugin ID. |
| `name` | Human-readable display name. | Appears in the catalog, installation prompts, and host UI. |
| `version` | Semantic version, for example `1.2.0`. | Each version is reviewed and addressed by its immutable artifact digest. Publish a new version for changed files. |
| `description` | Short explanation of the plugin. | Helps users and reviewers understand the plugin before installation. |
| `publisher` | Publisher name or handle declared by the author. | Displays ownership information; the authenticated publisher and reserved namespace are checked separately. |
| `license` | License label such as `MIT`. | Communicates redistribution terms. |
| `homepage` | Public HTTPS information page. | Gives users a support or product destination. |
| `repository` | Public HTTPS source repository. | Gives reviewers and users a source location when one is available. |
| `engines.classroomio` | Declared ClassroomIO compatibility string. | Required package metadata for review; the current validator checks that it is non-empty but does not resolve the range. |
| `engines.pluginApi` | Declared Plugin API compatibility string. | Required package metadata for review; the current validator checks that it is non-empty but does not negotiate a runtime version. |

`id`, `version`, and the packaged archive digest form the release identity. Changing any packaged
file without changing the digest is rejected.

## `icon`

`icon.resource` is a relative path to an image included in the archive. The host resolves it
against the approved artifact; it cannot be an arbitrary remote URL. Supported formats are SVG,
PNG, JPEG, and WebP. Use an icon for catalog cards and host-rendered navigation/actions, not for
loading executable code.

## `runtime`

The `runtime` block defines the UI entrypoints rendered by the plugin in the browser.

### `runtime.ui.entrypoints`
A key-value dictionary mapping entrypoint names to relative file paths:

```json
"runtime": {
  "ui": {
    "entrypoints": {
      "banner": "dist/banner.html",
      "adminPanel": {
        "resource": "dist/admin.html",
        "renderMode": "custom"
      }
    }
  }
}
```

Each entrypoint key is a name referenced by `contributes.pages`, `contributes.slots`, or custom
actions. Its value is either a relative asset path or an object with `resource` and
`renderMode: "custom"`. Paths must resolve to a valid packaged file; never use absolute paths or
`..` traversal segments.

## `contributes`

Specifies where and how the plugin renders inside the ClassroomIO dashboard.

### `contributes.slots`
Inline widgets embedded directly into specific dashboard surfaces:

```json
"slots": [
  {
    "id": "quiz-widget",
    "target": "lesson.after",
    "entrypoint": "quiz",
    "title": "Interactive Quiz",
    "renderMode": "custom"
  }
]
```

- `id`: Unique identifier for the contribution slot.
- `target`: Supported mounting slot: `lms.banner`, `course.sidebar`,
  `course.newsfeed.aside`, `lesson.before`, `lesson.after`, `certificate.templates`, or `landing.templates`.
- `entrypoint`: Name matching a key in `runtime.ui.entrypoints`.
- `title`: Label used for accessibility and framing.
- `renderMode`: `"custom"` (renders the sandboxed iframe).

### `contributes.pages`
Full-page standalone dashboards rendered at `/org/:slug/plugins/:pluginId`:

```json
"pages": [
  {
    "id": "analytics-view",
    "entrypoint": "analytics",
    "title": "Academy Analytics"
  }
]
```

### `contributes.navigation`
Links registered in the sidebar or top navigation:

```json
"navigation": [
  {
    "id": "nav-analytics",
    "title": "Analytics Pro",
    "location": "organization.navigation",
    "page": "analytics-view",
    "icon": { "resource": "dist/icon.svg" },
    "visibility": "admin"
  }
]
```

- `location`: `organization.navigation`.
- `page`: ID of the page declared in `contributes.pages`.
- `visibility`: `"admin"`, `"tutor"`, `"learner"`, or `"all"`.
- `order`: Integer ordering key. Ties are resolved by plugin ID and contribution ID.
- `pageModes`: `"view"` and/or `"edit"`; the host omits contributions outside the current page mode.

### `contributes.actions`
Contextual action buttons and menu items:

```json
"actions": [
  {
    "id": "add-certificate-to-profile",
    "target": "certificate.actions",
    "label": "Add to profile",
    "actionType": "openUrl",
    "urlTemplate": "https://profiles.example.com/certificates/add?name={certificateName}",
    "icon": { "resource": "dist/profile-icon.svg" }
  }
]
```

Only host-rendered `certificate.actions` URL actions are supported in v1.
`urlTemplate` must be HTTPS and its origin must be listed in
`networkAccess.allowedDomains`. Arbitrary commands, dialogs, and custom action
frames are not part of the hosted plugin contract.

Every custom slot, page, or navigation item must reference a declared UI entrypoint.
Every navigation item must reference a declared page. These checks prevent a manifest from
advertising a contribution that cannot render.

## `permissions`

ClassroomIO uses granular, OAuth-compatible scopes. When an academy admin installs your plugin, they are presented with a consent screen showing exactly what your plugin can access.

```json
"permissions": {
  "required": [
    "course.metadata:read",
    "lesson.metadata:read"
  ]
}
```

### Available Permission Scopes

| Scope | Description |
| :--- | :--- |
| `identity.profile:read` | Read the current user's limited plugin profile. |
| `organization.profile:read` | Read the current organization's limited plugin profile. |
| `course.metadata:read` | Read course metadata. |
| `course.content:read` | Read course section and lesson structure. |
| `lesson.metadata:read` | Read lesson metadata. |
| `lesson.content:read` | Read sanitized lesson content and attachments. |
| `learner.progress:read` | Read the current learner's lesson or course progress. |
| `learner.progress:write` | Update the current learner's lesson completion. |
| `exercise.metadata:read` | Read exercise metadata without learner answers. |
| `certificate.issued:read` | Read issued certificates available to the current actor. |
| `certificate.template:read` | Read the available and applied certificate templates. |
| `certificate.template:write` | Apply a certificate template in the `certificate.templates` surface. |
| `plugin.storage:read` | Read this installation's isolated plugin storage. |
| `plugin.storage:write` | Write this installation's isolated plugin storage. |

Other capability names may appear in platform planning documents, but only active scopes listed by
the current Plugin API are accepted by `npm run pack` and the host validator. A planned scope
must not be added to a production manifest until its API, authorization, tests, and documentation
are released.

:::warning[Principle of Least Privilege]
Only request permissions your plugin strictly requires. Plugins requesting sensitive scopes such as `lesson.content:read` or write access undergo deeper review before public directory approval.
:::

The `required` array blocks installation unless the organization grants every listed scope. The
`optional` array allows additional capabilities to be granted without making them prerequisites
for the base installation. A manifest scope is only a request: every API route still checks the
issued installation grant and the caller's organization and actor authorization.

## `settings`

`settings.schema` optionally describes configuration values exposed by the plugin's settings
surface. It is metadata for validation and rendering; secrets must not be placed in the manifest.

```json
"settings": {
  "schema": {
    "type": "object",
    "properties": {
      "enabled": { "type": "boolean" }
    }
  }
}
```

## `dataPolicy`

This required declaration tells users and reviewers how the plugin handles customer data:

```json
"dataPolicy": {
  "storesCustomerData": true,
  "retentionAfterUninstallDays": 30,
  "privacyPolicyUrl": "https://example.com/privacy"
}
```

- `storesCustomerData` must accurately state whether the plugin stores customer or tenant data.
- `retentionAfterUninstallDays` is an integer from `0` to `90` describing the intended cleanup
  window.
- `privacyPolicyUrl` is required when `storesCustomerData` is `true`.

This declaration does not replace the plugin's legal obligations or the host's retention controls.

## `storage`

Persistent plugin values are stored by ClassroomIO. Each accessible namespace and scope must be
declared before the browser SDK can read or write it.

```json
"storage": {
  "documents": [
    {
      "namespace": "preferences",
      "scope": "user",
      "schemaVersion": 1,
      "schema": {
        "type": "object",
        "properties": {
          "compact": { "type": "boolean" }
        },
        "required": ["compact"],
        "additionalProperties": false
      }
    }
  ]
}
```

- `namespace` is 1–64 characters and is unique within a scope.
- `scope` is `organization`, `user`, or `resource`.
- `schemaVersion` is a positive integer passed to storage writes.
- `schema` uses the supported JSON-schema subset: scalar/object/array types, properties, required
  keys, additional-properties control, items, bounds, pattern, enum, and const.

The manifest supports at most 32 storage documents. Declaring a document does not grant access;
the plugin must also request `plugin.storage:read` and/or `plugin.storage:write`.

## `extensions`

`extensions` is optional namespaced metadata for compatible host integrations. Unknown extension
keys do not grant capabilities. Never put secrets, private keys, or executable source in this field.

## `networkAccess` (Content Security Policy)

Because custom plugins render in an iframe, the ClassroomIO asset server dynamically generates a hardened **Content Security Policy (CSP)** for your plugin assets.

If your plugin UI needs to connect to an external public API, error-reporting service, or other
third-party web service, whitelist its origin in `allowedDomains`:

```json
"networkAccess": {
  "allowedDomains": [
    "https://api.my-plugin.com",
    "https://sentry.io"
  ]
}
```

### Rules for `allowedDomains`:
1. Every domain must begin with `https://`.
2. Must be an exact origin without wildcards, paths, or query strings (e.g. `https://api.example.com`, NOT `https://*.example.com`).
3. ClassroomIO compiles this into the response header:
   ```http
   Content-Security-Policy: default-src 'self'; connect-src 'self' https://api.my-plugin.com https://sentry.io; script-src 'self'; ...
   ```
4. If `allowedDomains` is empty or omitted, `connect-src` defaults to `'none'`, blocking all external HTTP/WebSocket requests from the iframe.
