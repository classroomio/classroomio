The Server SDK (`@classroomio/plugin-sdk/server`) provides a typed, resource-oriented HTTP client for your backend services. It runs in Node.js, Bun, Deno, Next.js, or serverless environments to perform privileged operations against ClassroomIO's Public Plugin API.

---

## Installation

```bash
npm install @classroomio/plugin-sdk
# or
pnpm add @classroomio/plugin-sdk
```

---

## Initialization

Initialize the client with your access token and the ClassroomIO API base URL:

```typescript
import {
  createClassroomIOPluginServerClient,
  ClassroomIOPluginServerClient,
  PluginApiError
} from '@classroomio/plugin-sdk/server';

const client = createClassroomIOPluginServerClient({
  baseUrl: 'https://api.classroomio.com',
  accessToken: process.env.CLASSROOMIO_ACCESS_TOKEN!
});
```

### Options

| Option | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `baseUrl` | `string` | **Yes** | ClassroomIO API base URL (e.g. `https://api.classroomio.com` or `http://localhost:3002`). |
| `accessToken` | `string` | **Yes** | Scoped Bearer token (obtained via OAuth2 or Launch Code exchange). |
| `fetch` | `typeof fetch` | No | Custom `fetch` implementation (defaults to `globalThis.fetch`). |

## Authenticating Your Backend

ClassroomIO provides two authentication mechanisms for plugin backends:

### 1. Launch Code Exchange (User-initiated)
When your frontend iframe requests a launch code via `client.auth.requestLaunchCode()`, exchange it on your backend for a scoped token:

```typescript
const response = await fetch('https://api.classroomio.com/plugin-api/v1/auth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    grantType: 'launch_code',
    code: req.body.launchCode,
    clientId: process.env.CIO_CLIENT_ID,
    clientSecret: process.env.CIO_CLIENT_SECRET
  })
});

const { accessToken, expiresIn, grantedScopes } = await response.json();
const client = createClassroomIOPluginServerClient({ baseUrl: '...', accessToken });
```

### 2. Machine-to-Machine Credentials (Background Jobs)
For scheduled synchronization or webhook processing without an active student session, authenticate using OAuth2 Client Credentials:

```typescript
const response = await fetch('https://api.classroomio.com/plugin-api/v1/auth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    grantType: 'client_credentials',
    clientId: process.env.CIO_CLIENT_ID,
    clientSecret: process.env.CIO_CLIENT_SECRET
  })
});

const { accessToken } = await response.json();
```

## Identity & Organization

### Current Identity (`client.identity`)
Retrieves the profile of the authenticated caller (requires `identity.profile:read`):

```typescript
const identity = await client.identity.getProfile();

console.log(identity.id);          // User profile UUID
console.log(identity.displayName); // "Jane Doe"
console.log(identity.role);        // "student" | "tutor" | "admin"
console.log(identity.locale);      // "en"
```

### Current Organization (`client.organization`)
Retrieves the active organization details (requires `organization.profile:read`):

```typescript
const org = await client.organization.getProfile();

console.log(org.id);        // Organization UUID
console.log(org.name);      // "ClassroomIO Academy"
console.log(org.avatarUrl); // "https://..."
```

## Courses (`client.courses`)

Manage course metadata, syllabus structures, and student enrollments (requires the corresponding `course.*` scopes):

### List Courses with Pagination
```typescript
const page = await client.courses.list({
  limit: 20,
  cursor: 'eyJpZCI6...' // Optional cursor for next page
});

for (const course of page.items) {
  console.log(course.id, course.title, course.published);
}

if (page.pageInfo.hasNextPage) {
  const nextPageCursor = page.pageInfo.endCursor;
}
```

### Get Course by ID
```typescript
const course = await client.courses.get('course-uuid-123');
console.log(course.title, course.slug, course.description);
```

### Get Full Course Syllabus Structure
Returns sections and ordered lesson references:

```typescript
const structure = await client.courses.getStructure('course-uuid-123');

for (const section of structure.sections) {
  console.log(`Section ${section.order}: ${section.title}`);
  for (const lesson of section.lessons) {
    console.log(`  - Lesson: ${lesson.title} (${lesson.type})`);
  }
}
```

### List Course Enrollments
```typescript
const enrollments = await client.courses.listEnrollments('course-uuid-123', { limit: 50 });

for (const enrollment of enrollments.items) {
  console.log(enrollment.profileId, enrollment.role, enrollment.status);
}
```

## Lessons (`client.lessons`)

Access lesson content and metadata (requires `lesson.metadata:read` or `lesson.content:read`):

### List Lessons in a Course
```typescript
const lessons = await client.lessons.listByCourse('course-uuid-123');
for (const lesson of lessons.items) {
  console.log(lesson.title, `${lesson.estimatedMinutes} mins`);
}
```

### Get Lesson Content (Markdown & Attachments)
Requires the sensitive `lesson.content:read` permission:

```typescript
const lesson = await client.lessons.getContent('lesson-uuid-456');

console.log(lesson.title);
console.log(lesson.content); // Full Markdown body
for (const attachment of lesson.attachments) {
  console.log(attachment.name, attachment.url, attachment.type);
}
```

## Student Progress (`client.progress`)

Read and write student completion states (requires `learner.progress:read` and `learner.progress:write`):

### Check Lesson Progress
```typescript
const progress = await client.progress.getLesson('lesson-uuid-456');
console.log(progress.isComplete);   // boolean
console.log(progress.completedAt);  // ISO timestamp or null
```

### Mark Lesson Complete
```typescript
const updated = await client.progress.setLesson('lesson-uuid-456', true);
console.log('Completed at:', updated.completedAt);
```

### Reset Lesson Progress
```typescript
await client.progress.resetLesson('lesson-uuid-456');
```

### Get Overall Course Progress
```typescript
const courseProgress = await client.progress.getCourse('course-uuid-123');
console.log(`Completed: ${courseProgress.completedLessons} / ${courseProgress.totalLessons}`);
console.log(`Percentage: ${courseProgress.percentage}%`);
```

## Certificates (`client.certificates`)

Interact with certificate credentials and templates (requires the corresponding `certificate.*` scopes):

### List Issued Certificates
```typescript
const issued = await client.certificates.listIssued({
  courseId: 'course-uuid-123',
  limit: 20
});

for (const cert of issued.items) {
  console.log(cert.recipientName, cert.certificateNumber, cert.issuedAt);
}
```

### Apply a Template to a Course
```typescript
const result = await client.certificates.apply('course-uuid-123', {
  templateId: 'minimal',
  design: {
    primaryColor: '#2563eb',
    accentColor: '#1e40af',
    issuerTitle: 'Lead Instructor'
  }
});

console.log('Template applied:', result.templateId);
```

## Persistent Storage (`client.storage`)

ClassroomIO provides managed, host-owned document storage (`plugin_storage`). No external database is needed. Declare the namespace in `plugin.json` and request `plugin.storage:read` and `plugin.storage:write`.

```typescript
// 1. Write document (organization scope)
await client.storage.set('analytics', 'course_stats', { views: 1250, avgScore: 92.4 }, {
  scope: 'organization'
});

// 2. Read document
interface Stats { views: number; avgScore: number }
const record = await client.storage.get<Stats>('analytics', 'course_stats', { scope: 'organization' });
console.log(record.value.views);

// 3. List documents by key prefix
const records = await client.storage.list<Stats>('analytics', { scope: 'organization' });

// 4. Delete document
await client.storage.delete('analytics', 'course_stats', { scope: 'organization' });
```

## Error Handling (`PluginApiError`)

All API failures are normalized into `PluginApiError` instances containing structured diagnostic information:

```typescript
try {
  const course = await client.courses.get('invalid-id');
} catch (error) {
  if (error instanceof PluginApiError) {
    console.error(`Error Code: ${error.code}`);       // e.g. "not_found", "forbidden"
    console.error(`HTTP Status: ${error.status}`);     // e.g. 404, 403
    console.error(`Request ID:  ${error.requestId}`);  // Unique correlation ID for tracing
    console.error(`Retryable:   ${error.retryable}`);  // boolean (true on 429/503)

    if (error.status === 429) {
      console.log('Rate limit exceeded. Backing off...');
    }
  } else {
    throw error;
  }
}
```

### Standard Error Codes

| Error Code | HTTP Status | Description |
| :--- | :--- | :--- |
| `unauthorized` | 401 | Invalid or expired Bearer access token. |
| `forbidden` | 403 | Missing required permission scope. |
| `not_found` | 404 | Requested course, lesson, or resource does not exist. |
| `rate_limited` | 429 | Rate limit exceeded. Backoff and retry with jitter. |
| `invalid_request` | 400 | Request validation failure (malformed JSON or query parameter). |
| `internal_error` | 500 | ClassroomIO internal server error. |
