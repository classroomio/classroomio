---
title: Slots and UI Surfaces
description: Supported contribution targets, dimensions, resources, and host handoffs.
---

Plugins declare contributions in `plugin.json`; they cannot inject arbitrary scripts into
ClassroomIO pages. The host resolves active, approved installations, filters contributions by
role and page mode, then mounts custom UI in a sandboxed iframe.

All current surface contracts are version 1. Contributions are ordered by `order`, plugin ID, and
contribution ID.

## Supported targets

| Target | Contribution | Resource | Height | Host behavior |
| --- | --- | --- | --- | --- |
| `lms.banner` | Custom slot | None | 48–320px | Inline learner-layout banner |
| `course.sidebar` | Custom slot | Course | 120–1200px | Course sidebar widget |
| `course.newsfeed.aside` | Custom slot | Course | 120–1200px | Course newsfeed sticky aside column |
| `lesson.after` | Custom slot | Lesson | 80–1600px | Widget below lesson content |
| `certificate.actions` | Host action | Certificate | Host rendered | Opens one declared HTTPS URL |
| `certificate.templates` | Custom slot | Course | 320–1600px | Template picker with typed apply handoff |
| `landing.templates` | Custom slot | Organization | 320–1600px | Editor picker with typed preview/select handoff |
| `organization.navigation` | Host navigation | Organization | Host rendered | Opens a declared plugin page |
| `plugin.page` | Custom page | Organization | 480–4000px | Full organization content route |

Every target is marked mobile-compatible by the version-1 contract. Plugin authors remain
responsible for responsive content inside the iframe.

Custom frames use `sandbox="allow-scripts allow-forms"`, a no-referrer policy, and no
same-origin access. Camera, microphone, geolocation, and clipboard write are disabled. The frame
has an accessible title. While it loads, the host displays a muted overlay; if the browser emits a
frame error, the host displays the contribution title as an alert. The host does not currently
render a retry control or detailed plugin error message.

Resize requests are clamped to the active target's range. All custom surfaces can use the generic
theme, toast, resize, dirty-state, preference, storage, and host-relative navigation bridge methods.
Typed data methods additionally require their declared and granted scopes.

## Inline slots

Declare `lms.banner`, `course.sidebar`, `course.newsfeed.aside`, or `lesson.after` in `contributes.slots` and reference a
packaged UI entrypoint.

```json
{
  "runtime": {
    "ui": {
      "entrypoints": {
        "lessonWidget": "dist/lesson-widget.html"
      }
    }
  },
  "contributes": {
    "slots": [
      {
        "id": "lesson-widget",
        "target": "lesson.after",
        "entrypoint": "lessonWidget",
        "title": "Lesson widget",
        "visibility": "learner",
        "pageModes": ["view"],
        "order": 10
      }
    ]
  }
}
```

Use a `ResizeObserver` when the rendered height can change:

```typescript
import { createClassroomIOClient } from '@classroomio/plugin-sdk/client';

const client = createClassroomIOClient();
const observer = new ResizeObserver(() => {
  void client.ui.resize(document.documentElement.scrollHeight);
});

observer.observe(document.body);
```

The `lms.banner` surface has no resource object. `course.sidebar` receives a course resource, and
`lesson.after` receives a lesson resource through `context.surface.resource`.

## Full plugin pages and navigation

A page requires a `contributes.pages` record. Organization navigation can link to that page by ID.

```json
{
  "runtime": {
    "ui": {
      "entrypoints": {
        "dashboard": "dist/dashboard.html"
      }
    }
  },
  "contributes": {
    "pages": [
      {
        "id": "analytics",
        "entrypoint": "dashboard",
        "title": "Academy analytics"
      }
    ],
    "navigation": [
      {
        "id": "analytics-navigation",
        "title": "Analytics",
        "location": "organization.navigation",
        "page": "analytics",
        "visibility": "admin"
      }
    ]
  }
}
```

The organization route includes both plugin ID and page ID. Navigation should be the normal entry
point; plugins should not construct the route from an assumed URL shape.

## Certificate actions

Version 1 supports only host-rendered `openUrl` actions on `certificate.actions`.

```json
{
  "contributes": {
    "actions": [
      {
        "id": "add-to-profile",
        "target": "certificate.actions",
        "label": "Add to profile",
        "actionType": "openUrl",
        "urlTemplate": "https://profiles.example.com/certificates/add?name={certificateName}"
      }
    ]
  },
  "networkAccess": {
    "allowedDomains": ["https://profiles.example.com"]
  }
}
```

The URL must be HTTPS and its exact origin must be in `networkAccess.allowedDomains`. Custom action
iframes, commands, and dialog handoffs are not supported.

## Certificate template picker

Declare a custom `certificate.templates` slot. The surface receives the current course and selected
template details. A picker can read available templates with `client.certificateTemplates` and
request application with `client.certificateTemplates.apply(...)`. Application requires
`certificate.template:write` and is accepted only on this surface.

## Landing template picker and public renderer

`landing.templates` requires all of the following:

- `pickerEntrypoint` for the authenticated landing-page editor;
- `publicRendererEntrypoint` for the public organization page;
- `publicViewModelVersion: 1`;
- at least one declared template, each with a packaged thumbnail.

The picker uses `client.landingTemplates.preview()` and `client.landingTemplates.select()`. The
public entrypoint uses `@classroomio/plugin-sdk/public-landing`, not the authenticated client. It
receives a constrained public view model and can request resize, navigation, or authentication.
