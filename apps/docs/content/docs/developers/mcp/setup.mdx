---
title: Connect an MCP client
description: Connect Claude Code, Codex, Cursor, OpenCode, or another MCP client to ClassroomIO by signing in with your ClassroomIO account.
---

Connect to the hosted ClassroomIO MCP server at `https://mcp.classroomio.com`. Your client opens a ClassroomIO sign-in page, you choose the workspace and approve the permissions, and the client receives access. You do not create or paste a key, and you do not install anything.

You must be an admin of the workspace you connect. To connect Claude or ChatGPT, see [Connect from Claude or ChatGPT](/developers/mcp/remote).

:::warning[The npm package is deprecated]
The local `@classroomio/mcp` package that runs through `npx` is deprecated. It keeps working for now, but it needs a key and a Node.js install, and new features are built for the hosted server. Move to the hosted server using the steps below. The package is still the only way to use `upload_video`, because that tool reads a file from your own computer.
:::

## Claude Code

Add the server, then sign in from the `/mcp` menu inside Claude Code:

```bash
claude mcp add --transport http classroomio https://mcp.classroomio.com
```

Run `/mcp`, select `classroomio`, and follow the browser prompt.

## Codex

Add this entry to `~/.codex/config.toml`:

```toml
[mcp_servers.classroomio]
url = "https://mcp.classroomio.com"
```

Then sign in:

```bash
codex mcp login classroomio
```

## Cursor

Add this entry to `~/.cursor/mcp.json`, or to `.cursor/mcp.json` for one project:

```json
{
  "mcpServers": {
    "classroomio": {
      "url": "https://mcp.classroomio.com"
    }
  }
}
```

Cursor shows a sign-in prompt for the server the first time it connects.

## OpenCode

Put this entry in your project's `opencode.json`, or in `~/.config/opencode/opencode.json` for all projects:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "classroomio": {
      "type": "remote",
      "url": "https://mcp.classroomio.com"
    }
  }
}
```

OpenCode starts the sign-in the first time the server needs it. You can also run `opencode mcp auth classroomio`.

## Check the connection

Restart the client, check that ClassroomIO tools appear, and ask it to list the courses in your workspace. If the tools are missing, check that the client loaded the config. If the client says it is unauthorized, sign in again, and confirm that you are still an admin of the workspace. You can see and remove connected apps in **Automation → MCP → Connected apps**.

Client config formats can change. If an example no longer matches your installed client, check its [Claude Code](https://code.claude.com/docs/en/mcp), [Codex](https://developers.openai.com/codex/mcp), [Cursor](https://cursor.com/docs/mcp), or [OpenCode](https://opencode.ai/docs/mcp-servers) documentation.

## Local server with a key (deprecated)

Create an MCP key in **Automation → MCP** and install Node.js so your client can run `npx -y @classroomio/mcp`. Set `CLASSROOMIO_API_KEY` in the environment that starts your client. The examples pass that variable to the server without putting the key in a config file.

The server also needs `CLASSROOMIO_API_URL=https://api.classroomio.com`. For a self-hosted installation, use your API URL instead.

### Claude Code

Add a `classroomio` entry to your `.mcp.json`:

```json
{
  "mcpServers": {
    "classroomio": {
      "command": "npx",
      "args": ["-y", "@classroomio/mcp"],
      "env": {
        "CLASSROOMIO_API_URL": "https://api.classroomio.com",
        "CLASSROOMIO_API_KEY": "${CLASSROOMIO_API_KEY}"
      }
    }
  }
}
```

### Codex

Add this entry to `~/.codex/config.toml`:

```toml
[mcp_servers.classroomio]
command = "npx"
args = ["-y", "@classroomio/mcp"]
env_vars = ["CLASSROOMIO_API_KEY"]

[mcp_servers.classroomio.env]
CLASSROOMIO_API_URL = "https://api.classroomio.com"
```

### Cursor

Add this entry to `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "classroomio": {
      "command": "npx",
      "args": ["-y", "@classroomio/mcp"],
      "env": {
        "CLASSROOMIO_API_URL": "https://api.classroomio.com",
        "CLASSROOMIO_API_KEY": "${env:CLASSROOMIO_API_KEY}"
      }
    }
  }
}
```

### OpenCode

Put this entry in your project's `opencode.json`, or in `~/.config/opencode/opencode.json` for all projects:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "classroomio": {
        "type": "local",
        "command": ["npx", "-y", "@classroomio/mcp"],
        "environment": {
          "CLASSROOMIO_API_URL": "https://api.classroomio.com",
          "CLASSROOMIO_API_KEY": "{env:CLASSROOMIO_API_KEY}"
        }
      }
    }
  }
}
```

### Check the connection

Restart the client and check that ClassroomIO tools appear. Ask it to list courses in the intended organization. If the tools are missing, check that Node.js can run the package and that the client loaded the config. If the request is unauthorized, check the API URL, key status, scopes, and key creator's permissions.

Client config formats can change. If an example no longer matches your installed client, check its [Claude Code](https://code.claude.com/docs/en/mcp), [Codex](https://developers.openai.com/codex/config-reference), [Cursor](https://docs.cursor.com/context/model-context-protocol), or [OpenCode](https://opencode.ai/v2/docs/mcp-servers) documentation.
