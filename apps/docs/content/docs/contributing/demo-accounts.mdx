This guide will help you get started quickly once you setup our local environment and you want to start using the [dashboard](https://app.classroomio.com).

:::note
The assumption of this guide is that you've followed the [Developers Guide](/contributing/devs) —
Postgres and Redis running via Docker, and the database seeded with `pnpm --filter @cio/db db:setup:seed` — and you have `dashboard` running locally.
:::

## Admin Login Credentials

Once you have the `dashboard` service running locally and the database seeded, you have access to an admin account to a demo organization and a student account to a student dashboard. This allows you see what ClassroomIO can do quickly without trying to figure it out.
