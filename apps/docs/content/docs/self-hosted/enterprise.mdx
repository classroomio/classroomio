ClassroomIO is [open core](/self-hosted/101#how-licensing-works): the complete LMS is free to
self-host, and a small set of enterprise features is unlocked by a paid license key. No key means
everything else still works, so leave `LICENSE_KEY` unset until you need one of these.

## What a license unlocks

| Feature | What it does |
|---------|--------------|
| **SSO** | Single Sign-On with OIDC (Okta, Azure AD, and more). See [Enterprise SSO setup](https://classroomio.com/help/integrations/enterprise-sso-setup). |
| **Token auth** | Issue signed tokens to log users in from your own app. Setup: [Token Auth](/developers/token-auth). |
| **No-tracking** | Disables third-party embeds and the [anonymous usage ping](/self-hosted/101#self-hosted-vs-cloud). Self-hosted mode already disables error reporting, product analytics and the feedback widget without it. |

Without a valid license, the SSO and token-auth APIs return `403 FEATURE_REQUIRES_LICENSE` and
their settings are hidden in the dashboard UI.

## Setting `LICENSE_KEY`

`LICENSE_KEY` is read by the **api** service, and by the **jobs** service to honour no-tracking. Set it wherever those services take their environment:

| Deployment | Where to set it |
|------------|-----------------|
| Docker | repository root `.env` |
| Railway | the `cio-api` and `cio-jobs` service environments |
| Coolify / Dokploy | the resource's environment variables |
| Local development | `apps/api/.env` |

```zsh title=".env"
LICENSE_KEY=<your enterprise license key>
```

Restart the stack with `./classroomio.sh restart` after setting it (this recreates the
`api` and `jobs` containers so they pick up the new value — `docker compose restart api` on its own
does **not**, since it doesn't recreate the container).

## How validation works

The api service validates the key against ClassroomIO's license server
(`enterprise-api.classroomio.dev`) and caches the result in memory for **one hour**.

What that means operationally:

- **The api container needs outbound HTTPS** to that host. In an air-gapped or egress-restricted
  network, licensed features can't activate. Contact ClassroomIO about your environment before
  buying.
- If a check fails (network blip, license server unreachable), licensed features switch off and
  the failure is also cached, so it can take **up to an hour** (or an api restart) after
  connectivity returns before they come back.
- Everything outside the licensed feature list is unaffected by license-server reachability.
