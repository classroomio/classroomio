Use **Content → Add content** to create a lesson or exercise. Select **Reorder** to arrange items and sections in the sequence students should follow.

![Course Content page in reorder mode with lessons and exercises](./images/create-and-reorder-lessons-and-exercises/overview.webp)

## Add a lesson or exercise

### 1. Choose where it belongs

Open your course's **Content** page. Use **Add content** for a new item in the outline, or the add control on a section to place it inside that section. Administrators and tutors with course access can edit content.

### 2. Create the item

Choose **Lesson** or **Exercise**, then select **Continue**.

- For a lesson, enter **Lesson Title** and select **Create lesson**.
- For an exercise, choose **From Scratch** or **Use a Template**, select **Next**, complete the title or template selection, and select **Finish**.

The item appears in the outline. Open it to add or review the actual learning material; creating a title does not finish the lesson or assessment.

## Reorder the outline

### 1. Start reordering

On **Content**, select **Reorder**. Drag handles appear on the content cards.

### 2. Move items into place

Drag a lesson or exercise to its new position. With grouping enabled, you can move it between sections, into a section, or out to the top level. Drag a section to move it together with its contents.

Changes save as items are dropped. Wait for saving to finish before making another move. If saving fails, the outline returns to its previous order; try again after checking your connection.

### 3. Finish and check the sequence

Select **End Reorder**. Open the first item and check the sequence in the sidebar. If you use **Sequential** progression, reordering changes the sequence students must complete, so review the effect on a course already in use.

The **Order Lessons Tab** setting changes the order of media tabs inside lessons; it does not reorder lessons or exercises.
