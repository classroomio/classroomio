Math questions let students type an expression instead of picking an option, and ClassroomIO checks the answer by value, not by exact spelling. Open an exercise's **Questions** tab to add them.

## Write math in questions and options

In a question title, a description or an option, wrap math between `$` signs, for example `$\frac{1}{2}+\frac{1}{4}$`. In the description editor, type `$` to open the math box, or use the math button in the toolbar. Selecting a formula opens it for editing.

## Math expression

Choose **Math expression** in the question type picker, then:

1. Add one or more **Accepted answers**. Any of them is accepted.
2. Choose how answers are compared: **Equivalent** accepts any algebraically equal form, **Exact form** also requires a form such as simplified, factored or expanded, **Numeric** accepts values within a tolerance, and **Set or list** ignores order.
3. Optionally set an expected unit, the variables, the keyboard students see, and feedback for known wrong answers.

Turn on **Let students answer with a photo or drawing** to add a **Photo or draw** button beside the student's answer box. It is off by default, because typed answers grade more reliably. The student reviews the converted math before it is used as their answer, and it is graded like any typed answer.

Use **Try an answer** to see how a sample student answer would be marked before you publish.

## Graph plot and graph reading

Use a graph question when the answer is a picture or a point on a graph rather than an expression.

### Graph plot

Choose **Graph plot** in the question type picker. Students plot points, lines, segments and parabolas on a coordinate plane, and the plot is graded automatically.

1. Under **Graph board**, set the edges of the graph (**Left edge**, **Right edge**, **Bottom edge**, **Top edge**), the axis labels, whether the grid shows, and **Snap to grid step**. Points snap to multiples of that number; use 0 to let students place points anywhere.
2. Under **Tools students can use**, choose which of **Point**, **Line**, **Segment** and **Parabola** students get.
3. Set **Tolerance**: how close, in graph units, a point or line must be to count as correct.
4. Under **Correct answer**, draw the answer on the board with the same tools. A line is drawn through two points, and a parabola with its vertex and one more point on it. Drag a point to move it. **Undo** removes the last element and **Clear** removes them all.
5. Check **Student view** to try the board the way students see it.

Students pick a tool, tap the board to place points, and drag a point to adjust it. A line matches when it passes close to both points of your line, so any two points on it work. A segment matches when both ends are close, in either order. A parabola matches when its vertex and its shape are close to yours. The score is the share of your elements the student matched, reduced by extra elements, so plotting everywhere does not earn credit.

In review, the student's graph is drawn over yours: green elements matched, red ones did not, and your correct answer shows dashed. The result says how many elements were correct.

### Graph reading

Choose **Graph reading** to show a graph and ask for a value or a point.

1. Set the **Graph board** as above.
2. Under **Functions on the graph**, add each function of x, for example `x^2 - 4`. Add a label if you like. Under **Marked points**, add points students can read from.
3. Choose what students read: **A single value** or **A point (x, y)**, then enter the correct value or coordinates and a tolerance. Answers within the tolerance are accepted.

Graph questions are graded automatically, so they also work in public courses.

## Import a worksheet

In the exercise editor, select **Import from worksheet** and choose a photo (PNG, JPEG or WebP) or a PDF of up to 10 MB. ClassroomIO reads each question as math, picks a type (math expression, numeric or single answer), proposes an answer, and shows your original beside the questions it found.

Every proposed answer is checked by the math engine against an expression or equation from the question. Questions it confirms are marked **Answer verified** and are selected. Questions it could not confirm are marked **Needs checking**, listed with the reason, and left unselected until you check them and tick them yourself. Edit any question, answer or option, then select **Import** to add the selected questions to the exercise. They are saved when you save the exercise.

Each import counts as one AI conversion, shared with the Photo and Draw tabs. Nothing from the file is stored.

## Hints for common mistakes

When a student's wrong answer matches a common slip, such as a sign error, a factor not applied to every term in brackets, an upside-down fraction, an inequality that was not reversed or a dropped factor, the review shows a short hint under the result. Feedback you write for a known wrong answer always replaces this hint.

## Worked solution

A **Worked solution** asks for a final answer and the student's working. The final answer is graded automatically and counts for the points you set as **Points for the final answer**. The rest of the points are for the working, which you grade by hand or with an AI suggestion (see below). Choose whether students can show working as typed lines, a drawing, a photo, or any mix. When students type working, they can also add a line from a photo or drawing with **Photo or draw**; the converted math becomes a typed line you can read next to their original image.

### Mark working with an AI suggestion

Under a worked solution or a paragraph question, fill in the **Marking rubric**: list the steps a complete solution shows and the points each is worth, then turn on **Suggest marks with AI**. It is off by default.

When you grade a submission, select **Suggest marks with AI**. The AI reads the student's working against your rubric and proposes points for each step, the first step that goes wrong, a comment and a confidence. Select **Accept** to add the points to the grade, change them if you like, then select **Submit grades** to save. **Reject** marks the suggestion as rejected and adds no points. Students see nothing until you accept or grade the answer, and a single suggestion never changes a grade on its own.

On the **Submissions** page, a banner shows how many AI suggestions have high confidence (85% or more). Select **Accept N high-confidence suggestions** to accept them together. This saves those grades straight away, and a submission whose manually graded answers are all accepted is graded and released to the student.

Each suggestion you request uses your organization's AI credits and, on the free plan, counts as one AI conversion for the month. Accepting a suggestion does not.

## Give every student different numbers

Use **Variables** under a numeric, math expression or worked solution question to make the numbers change for each student. Select **Make this question parameterised**, then:

1. Add variables. Each has a one-letter name, a type (**Whole number**, **Decimal** or **Choice**) and a range or a list of values.
2. Write the names in double curly braces in the question, the options and the answer key, for example `{{a}}` and `{{b}}`.
3. Optionally add **Constraints** such as `a != 0`, and an **Answer formula** such as `b / a`. Write `{{answer}}` where the answer's value should appear, or in **Accepted answers**.
4. Select **Preview variants** to see several versions and their answers before you publish.

Each attempt gets its own numbers, and a retry gets new ones. The answer is checked against the numbers that student saw, and review screens show the student's own version.

## Split a question into parts

Under a question, select **Add part** to add parts (a), (b), (c). The question above them becomes the shared stem, and each part is answered and scored on its own. Adding a part sets the stem to 0 points, so the points belong to the parts. Review screens show each part's score and the total for the parts. Deleting the stem deletes its parts.

## Choose a calculator

Open the exercise's **Settings** tab and use **Calculator** to choose **No calculator**, **Four-function**, **Scientific** or **Graphing**. Students see a **Calculator** button while they answer.

The graphing calculator uses Desmos. To turn it on, an administrator enters a **Desmos API key** under **Settings**, **Customize LMS**, in the Course section. Without a key, exercises set to Graphing give students the scientific calculator.

## Match your region's notation

Academies that write `0,5` instead of `0.5` can change how math is written, shown and graded. Open **Settings**, **Customize LMS**, and find **Math notation** at the bottom. Only an administrator can change it. Then select **Save changes** in that card.

- **Decimal separator**: with **Comma**, students can type `0,5` and it is graded as 0.5 in math expression and numeric questions, and decimals written inside math, such as `$0.5$`, show with a comma in questions, options and answers. Numbers typed as plain text are not changed.
- **Thousands separator**: **None**, **Space**, **Comma** or **Dot**. Numbers written with that separator, such as `1 000,5` or `1.000,5`, are accepted in answers, and numbers with five or more digits inside math show it. The thousands separator cannot match the decimal separator.
- **Multiplication sign**: with **Dot**, a `\times` in your math shows as `·`.
- **Unit system**: a hint for authors and the AI assistant. It does not change grading.
- **Default keyboard level**: **Primary** opens the numbers keyboard, **Secondary** the algebra keyboard and **Advanced** the calculus keyboard, for questions that do not choose a keyboard themselves.

An answer that mixes separators, such as `1,000.5` under a decimal comma, is not accepted: it is marked wrong, or invalid for math expressions. Write your accepted answers the way you normally do: both `0.5` and `0,5` are read as 0.5. With a decimal comma, a comma between two digits is a decimal separator, so write lists with a semicolon or spaces.

To change the notation for one course, open the course's **Settings** and use **Math notation**. Turn off **Use organization default** and choose the settings for that course. Grading always uses the notation in force when the answer is submitted or regraded.

## See and fix what students answered

Open the exercise, then **Submissions**, then **Results grid**. Each row is a student's latest attempt and each column is a question, coloured by score: full marks, partial credit, wrong, awaiting grading, or no answer. A **Total** column and the student names stay in view while you scroll across many questions. Point at a cell to see the student's answer as math; for a question with variables it shows that student's own numbers. Select a cell to open the answer as the student sees it in review. Use the filters to show only students with a wrong answer, only attempts awaiting grading, or one cohort of the course. Results load 25 students at a time.

Select a question's column heading to open its **Answer groups**. Answers that mean the same thing are grouped, so `x = -3` and `x=-3.0` count as one group with a student count and the grade they received. Answers are grouped by their written form, so `2(x+1)` and `2x+2` stay in separate groups even when both are right. For each group you can:

- **Mark correct** or **Mark wrong** for everyone in the group.
- Give **Partial credit** with a number of points up to the question's points, including fractions such as 1.25.
- **Add feedback** that every student in the group sees under their answer in review.
- **Undo decision** to return the group to what the answer key gives.

A decision regrades every submission that already has that answer and recalculates each student's total, so the gradebook changes too. It is also kept on the question, so later submissions with the same answer get the same result. Marking a group correct does not change the accepted answers. Verdicts apply to auto-graded questions; for questions you grade by hand you can still add feedback. Paragraph and file answers are not grouped. For a question with variables, groups are separate for each student's numbers.
