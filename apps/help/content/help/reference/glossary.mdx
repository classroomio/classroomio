A glossary is a specialized reference tool that explains the terms used throughout a product, document, or field in plain language.

This glossary is designed for Help Center users who need quick definitions while learning how ClassroomIO works.

## Core ClassroomIO terms

| Term | What it means |
| --- | --- |
| **Academy** | Your public-facing site — the org homepage, course landing pages, and Explore. Students land here before and after signing in. URL: `<siteName>.myclassroomio.com` or your custom domain. |
| **LMS** | The authenticated learning area students enter after signing in. Contains Home, My Learning, Explore, Cohorts, and Settings. Reached via **Open Academy** or **Go to LMS** in the admin dashboard. |
| **Organization** | Your admin workspace — holds courses, people, settings, and branding. Each organization maps to one academy. |
| **Explore** | The course discovery tab inside the LMS. Shows published courses the student has not enrolled in yet. |
| **Academy landing page** | The public homepage for your academy. Editable in **Settings → Landing Page**. |
| **Course landing page** | The public page for a single course — description, price, and Enroll button. Editable from the course sidebar. |
| **Student** | A user enrolled in one or more courses. Has access to the LMS but not the admin dashboard. |
| **Audience** | Your org-wide student directory: everyone who belongs to your organization, whether they signed up, accepted a course invite, or were added directly. |
| **Course** | The primary learning container — holds lessons, exercises, people, and settings. |
| **Cohort** | A group of courses with a shared completion goal (complete all, pass rate, score). |
| **Enrollment** | Joining a course. Can happen via public self-enrollment, invite link, admin assignment, or payment. |
| **Invite** | An email sent to a specific person containing a unique enrollment link for a course or organization. |

## Related concepts

| Term | What it means |
| --- | --- |
| **Admin Dashboard** | The control center where organization admins manage courses, students, settings, branding, roles, and operations. |
| **Community** | An org-wide Q&A and discussion space for students and team members. |
| **Course type** | The mode a course uses, such as self-paced, live class, compliance, or public. |
| **Custom domain** | A branded domain for your academy site, such as `learn.example.com`. |
| **Exercise** | A graded or interactive task inside a course, such as a quiz or assignment. |
| **Invite link** | A direct URL used to send someone into a course or enrollment flow. |
| **Lesson** | A unit of teaching within a course. It may include notes, media, slides, or videos. |
| **Live class** | A scheduled class session with attendance and real-time participation. |
| **Progression** | The rule set that controls how students move through a course and when content unlocks. |
| **Publish state** | Whether a course or page is visible and available to students. |
| **Role and permissions** | The access level a user has inside an organization. |
| **Self-paced course** | A course students move through at their own pace instead of a live class structure. |
| **SSO** | Single Sign-On. A login method that uses your organization’s identity provider. |
| **Tag** | A label used to organize and filter courses and content. |
| **Team member** | A person added to an organization with a role such as admin or instructor. |
| **Welcome email** | The automated email students receive when they enroll or join a course. |

## Quick mental model

If you need the simplest explanation:

- An academy is the public learning site.
- An organization is the admin workspace.
- A course is the learning container.
- A student is the learner.
- An enrollment is the access event.
- A cohort is the group or batch structure.

This vocabulary is what makes the rest of the Help Center readable.
