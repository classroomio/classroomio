Design the certificate on the course's **Certificates → Design** tab. The preview lets you check the template and color before a student earns the finished document.

![Course Certificates design tab with a certificate preview](./images/design-a-course-certificate/overview.webp)

:::info[Paid plan required]
Certificate editing requires a paid plan. The controls are disabled on the Free plan.
:::

## Customize the design

1. Open the course and select **Certificates**. It opens on **Design**.
2. Select **Customize design** to open the editor.
3. Choose a **Template** and accent color while checking the live preview.
4. If the document needs signatures, fill in the [signatory fields](/deliver-and-engage/add-certificate-signatories).
5. Optionally set a **Certificate ID format**, then save the design.

:::warning[Finish the design before the first issue]
Certificates are generated from the current design when a student qualifies. Review the preview and signatories before releasing the course so the first issued certificate has the intended details.
:::

The design does not decide who qualifies. Set the completion threshold, final exercise, and optional deadline separately in the course's **Settings** tab.
