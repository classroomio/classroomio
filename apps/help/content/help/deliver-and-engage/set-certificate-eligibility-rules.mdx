Certificate eligibility is set on each course. A student must meet the configured course completion threshold and any final exercise or deadline requirement before ClassroomIO issues the certificate record.

![Course Certificates Settings tab with eligibility rules](./images/set-certificate-eligibility-rules/overview.webp)

:::info[Paid plan required]
Certificate controls are visible but disabled on the Free plan.
:::

## Set the requirements

1. Open the course's **Settings** tab and find the certificate rules near **Course type**.
2. Set **Minimum completion (%)**. It counts lesson and exercise progress together and defaults to 100%.
3. If a final assessment is required, choose **Final exercise (optional)** and set **Minimum score on final exercise (%)**. The student's best attempt counts, and this exercise allows unlimited attempts.
4. If completion must happen by a certain time, set **Course Completion Deadline**. The student's local time is used; finishing exactly at the deadline qualifies.
5. Save changes and test the rules with a demo student.

:::warning[Check existing students before changing the rules]
Changing the threshold, final exercise, or deadline can change who qualifies next. Review current progress and submissions before saving stricter requirements.
:::

The separate **Certificates → Settings** sub-tab controls whether an eligible student can download the certificate. Turning off download does not stop the student from earning the certificate record.
