---
title: Embed slides in a lesson
description: Paste an iframe embed code from Google Slides, Canva, PowerPoint, Keynote, Figma, Prezi, Pitch, Gamma, SlideShare, or Beautiful.ai.
---

A lesson can include **multiple** slide decks. On the **Slide** tab, click **Add slide**, pick the platform, and paste the **full iframe embed code** (not just a share link). ClassroomIO extracts the `src`, ignores the pasted width and height, and plays every deck at a consistent 16:9 size.

Each platform below has a stable heading so the picker can deep-link here (`#google-slides`, `#canva`, …).

## Google Slides {#google-slides}

1. Open the deck and choose **File → Share → Publish to web**.
2. Open the **Embed** tab and click **Publish**.
3. Copy the iframe code and paste it into ClassroomIO.

## Canva {#canva}

1. Above the editor, click **Share → More**.
2. Choose **Embed** and confirm (this makes the design public).
3. Copy the HTML embed code and paste it into ClassroomIO.

## PowerPoint {#powerpoint}

1. Save the deck to OneDrive and open it in **PowerPoint for the web**.
2. Choose **File → Share → Embed**.
3. Copy the iframe code and paste it into ClassroomIO.

Personal OneDrive embeds are viewable without signing in. Work/school OneDrive may show a Microsoft sign-in wall to learners.

## Keynote {#keynote}

1. Click **Collaborate** and set access to **Anyone with the link · View only**.
2. Copy the iCloud link, then get the website embed code.
3. Paste the iframe code into ClassroomIO. Keep collaboration enabled or the embed stops working.

## Figma Slides {#figma}

1. Open the Figma Slides file and enable link sharing.
2. Copy the embed code for the `/slides` or `/deck` file.
3. Paste the iframe code into ClassroomIO.

## Prezi {#prezi}

1. From the dashboard, open **Share** on the presentation.
2. Click **Embed** and copy the code.
3. Paste the iframe code into ClassroomIO.

## Pitch {#pitch}

1. Click **Share → Share externally** and create a public link.
2. Open the link **Options (⋯)** and choose **Copy embed code**.
3. Paste the iframe code into ClassroomIO. Disabling the public link breaks the embed.

## Gamma {#gamma}

1. Open **Share** and toggle **Allow public access**.
2. Copy the generated iframe embed code.
3. Paste it into ClassroomIO.

## SlideShare {#slideshare}

1. Open the public deck on slideshare.net.
2. Click **Share** under the viewer and open the **Embed** tab.
3. Copy the iframe code and paste it into ClassroomIO.

## Beautiful.ai {#beautiful}

1. Open **Sharing Settings** and switch the deck to **Public**.
2. Click **Get Embed Code**.
3. Paste the iframe code into ClassroomIO.
