---
title: Take Attendance
description: Record lesson attendance for each student in a course using the Attendance tab.
---

The **Attendance** tab in a course lets you track which students attended each lesson. Only students who are enrolled in the course appear in the attendance grid — enroll them first via **People** if they are missing. It displays a grid with students as rows and lessons as columns. A checked box means the student attended (present or late); unchecked means absent.

## Mark attendance

From the course dashboard, open the **Attendance** tab.

- Check the box at the intersection of a student and a lesson to mark them **Present**.
- Uncheck the box to mark them **Absent**.

Changes save immediately — there is no separate save button.

Course tutors and organization admins can record attendance. The web grid does not show late arrivals separately, and changing a box replaces a late mark with present or absent.

## Check-in codes in the mobile app

In the ClassroomIO mobile app, a tutor can start check-in for a live session. The app shows a 6-character code and a QR code. Learners enrolled in the course scan the QR code or type the code in the app to mark themselves present. A code expires after 15 minutes and stops working when the tutor creates a new one. Learners who check in more than 10 minutes after the session starts are recorded as late, and tutors can also mark present, late or absent from the app.

Use the search bar to filter students by name if the course has a large group.

:::info[Students see read-only attendance]
Students can view their own attendance record in the Attendance tab when they open the course in the LMS, but they cannot edit it.
:::

## Pagination

The table shows 10 students per page. Use the page controls at the bottom to move between pages.
