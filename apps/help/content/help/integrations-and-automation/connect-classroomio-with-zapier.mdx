The **Zapier** tab under **Automation** is a placeholder. A ClassroomIO integration for Zapier is not available yet, so there is nothing to connect, authorize, or turn on from this tab.

## What you see on the Zapier tab

1. From the admin dashboard, open **Automation** in the sidebar.
2. Select the **Zapier** tab.

The page shows the subtitle "Automate ClassroomIO with thousands of apps through Zapier. Coming soon." and a notice titled **Zapier** that says **Coming soon**. The tab has no buttons, settings, or connection form.

:::info[Admin access]
**Automation** is shown to organization administrators. Other members see it disabled in the sidebar, and the Automation area states that only organization admins can manage automation.
:::

## Automate with ClassroomIO today

Until the Zapier integration is released, you can still send ClassroomIO events to other tools:

- **Webhooks** send an HTTP request to a URL you control when something happens in your organization. Zapier can supply such a URL, as the [webhook guide](/integrations-and-automation/create-and-manage-webhooks) notes. Follow that guide to create one.
- **API** keys let your own application make authenticated requests. See [Create and manage API keys](/integrations-and-automation/create-and-manage-api-keys).

Both options have plan requirements, which the linked guides describe.
