Organization administrators manage MCP credentials under **Automation → MCP**. The page shows active-key usage, rate limits, key names, status, creation date, and last use.

![MCP keys list with status and key actions](./images/create-rotate-and-revoke-mcp-keys/overview.webp)

## Create a key

1. Select **Generate key**, enter a descriptive name, and save.
2. Copy the secret from the reveal dialog immediately. The full value is shown only at creation or rotation.
3. Store it in a secret manager, then use it as `CLASSROOMIO_API_KEY` in a [client setup](/integrations-and-automation/connect-claude-code-codex-cursor-or-opencode).

MCP keys are organization scoped. Review [permissions and limits](/integrations-and-automation/understand-mcp-limits-and-permissions) before sharing one with a client.

## Rotate or revoke

Open the key's action menu and choose **Rotate** to replace a secret. Copy the new value and update each client using that key; the previous secret stops working. Choose **Revoke** to stop a key entirely. Confirm the action and check that its status changes. To avoid an interruption, create a second key, update and test clients, then revoke the old key.

If you lose a secret, ClassroomIO cannot show it again. Rotate the key or create a new one. Never paste a live key into a support ticket or screenshot.
