Model Context Protocol (MCP) lets an AI client use ClassroomIO tools through the hosted ClassroomIO MCP server. The client plans the work; the server validates tool input and forwards authenticated requests to the ClassroomIO API.

![Automation MCP page listing connected apps with the Connections and MCP keys tabs](./images/understand-classroomio-mcp/overview.webp)

MCP supports draft-based course authoring and work with courses, exercises, cohorts, audience, and analytics. Creating a draft and publishing it are separate steps, so review draft content before publication. See [MCP access and limits](https://classroomio.com/docs/developers/mcp/access-and-limits) before connecting a client.

An organization administrator connects a client by signing in with their ClassroomIO account, choosing the workspace, and approving the permissions. The connection is limited to that workspace, to the permissions approved, and to the administrator's role. ClassroomIO checks those permissions at the API. A connected client is not a way to bypass a user's course role.

Only connect a trusted AI client. The client may receive course or student data returned by tools, so review the client's data-handling rules before granting access. [Connect your client](/integrations-and-automation/connect-claude-code-codex-cursor-or-opencode), and remove it under **Automation → MCP → Connected apps** when the connection is no longer needed. Keys created earlier can still be [rotated or revoked](/integrations-and-automation/create-rotate-and-revoke-mcp-keys).
