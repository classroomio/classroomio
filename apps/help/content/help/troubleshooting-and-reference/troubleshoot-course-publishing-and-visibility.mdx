A course can have a finished landing page but still be unpublished, unavailable for self-enrollment, or hidden from discovery. Check the live course settings and academy page before assuming the preview reflects what visitors see.

![Course landing page editor with the live preview](../publish-and-brand/images/preview-and-publish-a-course-landing-page/overview.webp)

## Check the course state

Open **Courses**, choose the course, and review **Settings**. Confirm that it is published and that self-enrollment matches the way students should join. An unpublished course will not work as a public enrollment destination. A course that requires an invitation may be available to assigned students without showing an open enrollment button.

Open **Landing page** and check the saved content, then visit the live academy course URL while signed out. The editor preview checks layout; the live page tests the actual sign-in, payment, and enrollment path. See [Preview and publish a course landing page](/publish-and-brand/preview-and-publish-a-course-landing-page).

## Check discovery and access separately

If the course opens from a direct link but is absent from **Explore** or the academy landing page, review the course's visibility and the academy's catalog section. A published course does not necessarily appear in every listing. A paid course may require completed checkout before the student can enter; an invitation-only course may require an accepted invitation.

If a student can open the course but not a lesson or exercise, check that item's availability and the course's progression rule. [Locked content](/learner-guides/understand-locked-content-and-progression) is a different issue from course publication.

## If the live page still differs

Refresh it in a private browser window and confirm you are using the intended academy URL and account. Tell the course team the course name, URL, intended audience, approximate time, and what the live page shows. Include a screenshot with personal data hidden.
