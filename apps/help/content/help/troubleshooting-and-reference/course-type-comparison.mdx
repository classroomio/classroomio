Choose a course type for the way people should access and complete its material. The four types change available tools and student flow; they do not publish the course or replace its separate enrollment and completion settings.

![Create a Course dialog showing the four course types](../create-and-deliver/images/course-types/overview.webp)

## Which type fits?

| Type           | Use it when                                | Main distinction                              |
| -------------- | ------------------------------------------ | --------------------------------------------- |
| **Self Paced** | Enrolled students learn on their schedule  | Standard course learning area                 |
| **Live Class** | Teaching includes scheduled sessions       | Instructor-led session and grading workflows  |
| **Compliance** | Training is required and must stay current | Due dates, current status, and renewal cycles |
| **Public**     | Visitors should read without signing in    | Anonymous access instead of normal enrollment |

Open **Settings → Course type** to review or change an existing course. Changing the type can alter access, completion, and which tools appear. Review current students, exercises, and course settings before saving, then test the result as a student or signed-out visitor.

For each type's setup and limitations, use [Compare ClassroomIO course types](/create-and-deliver/course-types). A [certificate](/troubleshooting-and-reference/certificate-and-compliance-cycle) can recognize completion, while only a compliance course tracks recurring training obligations.
