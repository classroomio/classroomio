The **Setup** page, titled **Get Started**, is a checklist inside the admin dashboard. It lists six tasks for launching your learning platform, marks the ones you have finished, and takes you to the right screen for the rest.

This is the in-product version of the checklist. [Complete your onboarding checklist](/get-started/onboarding) is the wider launch guide that also covers the landing page, enrollment, and testing as a student.

## Open the Setup page

While your setup is below 100% complete, a small progress ring appears in the dashboard header on larger screens.

- Select the ring to open the Setup page.
- Hover over the ring to see **Your Checklist**, a short list of the same tasks. Select an unfinished task to go to it, or use the refresh button to reload your progress.

Once every task is complete, the ring no longer appears.

## What the page shows

The page header shows **Get Started** and the line "Complete these steps to set up your learning platform", with a progress ring. Below it, a summary shows how many tasks are completed, for example "2 of 6 completed", with one dot per task.

Each task shows a title, a short description, and a **Todo** button. Completed tasks are dimmed and struck through, with a disabled **Done** button. Selecting a completed task does nothing.

## The six tasks

| Task                                             | What completes it                          | Where it takes you                                    |
| ------------------------------------------------ | ------------------------------------------ | ----------------------------------------------------- |
| **Upload a profile picture and update username** | Your profile has a picture                 | **Settings**                                          |
| **Update organisation profile picture**          | The organization has a logo                | The organization settings page                        |
| **Create Course**                                | The organization has at least one course   | The **Courses** page with the create dialog requested |
| **Create a lesson**                              | The organization has at least one lesson   | The lessons page of your first course                 |
| **Create an exercise**                           | The organization has at least one exercise | The first lesson of your first course                 |
| **Publish a course**                             | At least one course is published           | The publish section of your first course's settings   |

The lesson, exercise, and publish tasks depend on earlier ones. If you select **Create a lesson** or **Publish a course** before creating a course, a message says "You need to create a course". If you select **Create an exercise** before creating a lesson, it says "You Need to Create a lesson".
