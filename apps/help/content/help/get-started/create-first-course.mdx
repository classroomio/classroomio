Create a course from the organization home page, then add lessons or exercises and publish it when the content is ready. New courses use the self-paced course type initially; you can review the delivery type and other behavior in course settings.

## Create the course

### 1. Open the course creator

From the admin dashboard, select **Home** in the organization navigation. The course creator lets you describe the course you want or start from a prepared template.

### 2. Describe the course

Enter a clear prompt with the topic, audience, and desired outcome. Choose the student level, and select an available AI model if the picker is shown.

You can instead choose a template, such as product onboarding, to prefill a useful starting prompt. Edit the prompt so it matches your organization before creating the course.

### 3. Create the draft

Submit the prompt. ClassroomIO prepares a title and description, creates the self-paced course, and opens its **Lessons** area. The course remains under your control; review the generated details and content before publishing it.

:::note[AI credits]
Generating course details uses AI credits. If creation is unavailable because the included balance is exhausted, review [Understand usage and plan limits](/get-started/understand-usage-and-plan-limits).
:::

## Adding lessons

### 1. Add a lesson

Open **Lessons**, then select the add control. Enter the lesson details and save it. Open the lesson to add notes and supported learning materials.

### 2. Add an exercise

Use the course navigation to open **Exercises** and create an activity when students need to practise or demonstrate understanding. Configure the questions, grading behavior, and availability before assigning it.

See [Create an exercise](/create-and-deliver/create-exercise) for the complete workflow.

### 3. Review the student sequence

Arrange lessons and exercises in the order students should complete them. If you use progression rules or locked content, verify that the required sequence is achievable with a test-student account.

## Review course settings

Open **Settings** inside the course and confirm the course type, enrollment behavior, completion rules, landing-page details, and any certificate settings that apply. Different course types change how students experience delivery, so review [Understand course types](/create-and-deliver/course-types) before switching from self-paced.

## Preview and publish

Use **View as student** to inspect the course in its student layout. This view does not impersonate another account, so use a separately enrolled test student for the final access check.

When the course is ready, publish it from its settings and save the change. A published course can be exposed through your academy and enrollment flows; publishing alone does not automatically enroll students.

## What happens next

Choose how students should join the course, then test that exact path before sharing it broadly. Depending on your access model, you can enroll students directly, send invitations, share an invite link, or allow self-enrollment.
