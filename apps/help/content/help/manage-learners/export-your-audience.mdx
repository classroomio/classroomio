Use **Export as CSV** on **Audience** to download the current filtered list. Select rows first if the export should include only those students.

![Audience export menu showing Excel, PDF, and HTML options](./images/export-your-audience/overview.webp)

## Choose the students

Organization administrators open **Audience** and [search or filter the list](/manage-learners/browse-search-and-filter-your-audience).

With no individual rows selected, the export includes the filtered results across pages. With rows selected, it exports that selection instead. Check the active filters and selection count before downloading.

## Download the report

Select **Export as CSV** for a `.csv` file. Open **More export formats**, the button beside it, to choose Excel, PDF, or HTML.

The audience report includes names and emails, membership and invitation status, enrollment and completion counts, progress, last login, last activity, and join date. Use the student profile export when you need [one student's course and grade details](/manage-learners/view-a-learner-profile-and-activity).

If PDF is disabled for a large result set, narrow the filters or choose another format. For a large download, leave the page open until the file is ready.

## Copy selected rows

When you select students, the bulk action bar also offers **Copy** in CSV, JSON, or HTML form. Use this for pasting a small selection into another tool; use a downloaded report for a file you want to retain.

## Handle the file carefully

Audience exports contain personal information and learning records. Share them only with people who should see those records and store them in your organization's approved location.
