---
title: Embed a widget on another website
description: Copy a published widget into a page you manage.
last_reviewed: '2026-10-21'
---

Publish the widget before placing it on another site.

![Widget editor showing the hosted embed URL](./images/embed-a-widget-on-another-website/overview.webp)

1. Open **Distribute → Widgets** and choose the widget.
2. Select **Embed Code**. The **HTML** tab gives you embed code to paste into your website's HTML or embed block.
3. Use the **URL** tab if your site supports embedding a hosted URL instead.
4. Publish or save the external webpage and inspect the widget there.

If the external site strips iframe or script code, ask its site administrator which embed method it supports. After changing your widget, publish a new version and verify the external page still displays it. See [Use widget version history](/publish-and-brand/use-widget-version-history).
