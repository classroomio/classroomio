The **Courses** section of the academy landing page highlights selected courses for visitors.

![Academy landing page Courses editor and preview](./images/configure-the-course-catalog-section/overview.webp)

1. Open **Distribute → Landing Page → Customize** and select **Courses**.
2. Choose **Add courses**, search for the courses you want, and select them.
3. Reorder the selected courses by dragging them into the display order you prefer.
4. Save and check the public homepage.

Only published courses can work as public destinations. If a course does not appear as expected, check its [publish and self-enrollment settings](/build-courses/publish-a-course-and-allow-self-enrollment).
