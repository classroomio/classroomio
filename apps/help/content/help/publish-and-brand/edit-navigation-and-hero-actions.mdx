Use the academy landing page editor to direct visitors to the right content.

![Academy landing page Navigation editor and preview](./images/edit-navigation-and-hero-actions/overview.webp)

1. Open **Distribute → Landing Page → Customize**.
2. Select **Navigation** to add a link, then enter its label and destination URL. Remove links you no longer need.
3. Select **Hero** to edit the heading, supporting text, and primary button label and URL. Turn on the secondary button if you need a second action.
4. Save and open the live academy page to test every destination.

The landing page summary's **Nav** count is the number of configured links. Preview links are disabled, so test navigation on the published site. For calls to action on an individual course, see [Configure enrollment calls to action](/publish-and-brand/configure-enrollment-calls-to-action).
