Set **Banner Image** and **Banner Text** under **Settings → Customize LMS → Dashboard** to change the banner on the student dashboard. Save the draft, then check the result with a demo student account.

![Customize LMS page showing Banner Image and Banner Text](./images/customize-the-learner-dashboard-banner/overview.webp)

## Update the banner

1. Open your organization's **Settings** and select **Customize LMS**.
2. Under **Dashboard**, select **Update banner image**. Choose an image in the upload control and confirm it appears in the page preview.
3. Enter the message in **Banner Text**.
4. Select **Save changes** in the bottom action bar.

Use a short message that stays readable on narrow screens and an image that does not carry essential text. The banner fields do not set a link or action button.

If you change your mind before saving, select **Discard**. After saving, open the student learning area to confirm the image crop and text in context.
