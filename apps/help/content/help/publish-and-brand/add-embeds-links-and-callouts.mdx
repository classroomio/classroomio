The academy landing page editor includes optional sections for an embed, useful links, and a callout.

![Academy landing page Embed section toggle and preview](./images/add-embeds-links-and-callouts/overview.webp)

1. Open **Distribute → Landing Page → Customize**.
2. Select **Embed**, **Links**, or **Callout** and turn on the section you want.
3. For an embed, enter a title, description, and embed code. For links, add cards with a label and destination. For a callout, enter the heading, description, button label, and button URL.
4. Save and inspect the section on the live homepage.

Only paste embed code from a provider you trust. Check that its content and your links display correctly on both desktop and mobile.
