ClassroomIO · Prototype + plan handoff

Learner Usage & Lifecycle

An admin with tens of thousands of learners needs to answer one recurring question: who isn't using the platform, and who should we remove? That's a loop, not four features — and this prototype is the loop, running over 2,400 synthetic learners so counts, paging and select-all-matching behave at real scale.

SeeLast login and last activity as first-class columns, sortable oldest-first — because "who is most dormant" is the question
FilterA quiet view switcher for the four questions asked daily, and a full filter popover behind it
ReviewConfirmation shows a real sample and offers "export this list first" — the sign-off step
ActArchive, deactivate or delete in bulk — by ticked rows, or by all N matching the filter
ProveSeat count falls on archive, undo for reversible actions, audit reason on every batch

Design notes

Built on app-theme.css, which mirrors the real packages/ui/src/index.css tokens — OKLCH palette, Geist, the same radius and shadow scale. Every element maps to an existing @cio/ui primitive (Table, Popover, DropdownMenu, Dialog, Sheet, Checkbox, Badge, Progress, Empty, Pagination, Sonner). No new visual language, nothing shouting: counts sit muted inside menus rather than as coloured chips on the page, and status is carried by quiet badges, not colour blocks.
