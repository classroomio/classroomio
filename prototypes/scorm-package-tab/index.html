SCORM package tab · 3 design options

Same real content and actions as today's Package tab (details, stale-version notice, warnings, modules, upload new version / swap / remove). Only the presentation differs.

A · Package card

Lowest effort. One card with a stat strip; Swap and Remove move into a menu so “Upload new version” is the single primary action.

 B · Split with details rail

Modules as a timeline on the left; version facts, stale notice and all actions in a side rail. Best for packages with many modules.

 C · Status hero

Most polished. Gradient hero, icon stat tiles, collapsible warnings, and a modules table that shows grading per module.
