# Optional content marker prototype

Static mock comparing how the course sidebar marks required vs optional lessons and exercises.

- Open [`index.html`](./index.html) in a browser.
- Toggle **Current**, **Proposed** (Optional label on the exceptions) and **Alternative** (muted marker, only when a course mixes both).
- Switch between an all-required course and a mixed course.

This folder is not wired into the dashboard.
