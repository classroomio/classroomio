Embedded Academy

A ClassroomIO widget that renders a whole page instead of one block of course cards — then keeps going, all the way through course detail, lessons, and exercises, inside the customer's own product.

Draft PRD 10 screens Reference: the Claude app's Learn page
Index → Category → Course → Lesson → Exercise · never leaving the host app

Learner — inside the customer's product

Every screen renders in a mock host app so the embed's boundary is visible. Use the Bounds toggle to show where the widget starts and ends, and Inherit host to see the theme adopt the host's typography.
