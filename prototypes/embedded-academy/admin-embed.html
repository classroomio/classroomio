Embed & identity

Drop this academy into your product. Step 1 gets it rendering; steps 2 and 3 make it personal to each learner.

1Add the embedReady
<!-- where the academy should render -->
<div data-cio-widget="academy" data-widget-key="wgt_7Kq2mBx9"></div>
<script async type="module" src="https://embeds.classroomio.com/embeds/academy/academy.js"></script>

The loader is 3 kB. Course detail and the lesson player load only when a learner opens one.

2Sign a learner token on your serverToken auth active
// server-side, per request — never in the browser
const token = await new SignJWT({ sub: user.id, email: user.email, name: user.name })
  .setProtectedHeader({ alg: 'HS256' })
  .setIssuedAt()
  .setExpirationTime('2m')
  .sign(new TextEncoder().encode(process.env.CIO_TOKEN_AUTH_SECRET));

Uses your organization's existing token-auth signing secret. Manage or rotate it in Settings → Auth → Token auth.

3Hand the token to the embed
<div data-cio-widget="academy"
     data-widget-key="wgt_7Kq2mBx9"
     data-cio-token="<%= token %>"></div>

The embed exchanges this for a short-lived access token held in memory. Nothing is written to cookies or local storage, so the academy works in browsers that block third-party cookies.

4Routing

Zero conflict with your router. Refreshing returns to the academy index.

<div data-cio-widget="academy" data-widget-key="wgt_7Kq2mBx9"></div>
5Allowed origins

A leaked widget key cannot be re-hosted anywhere else. Leave blank to allow any origin.

!Personalization needs Enterprise

Token auth is an Enterprise feature. Without it the academy still renders for everyone — it just cannot show progress, Jump back in, or For you, and learners enrol on the academy rather than in place.
