Prototype · UX source of truth

Course templates

Docs/Slides-style: a “Create a new course” row on the courses page and a template gallery with no tabs. ClassroomIO’s four launch templates appear for every org. Spec: prd/course-templates/README.md. Every screen has a state bar in the bottom-left.

Journeys

Make a template: Course ⋯ menu → Save as template → Template
Use a template: Template row or Template gallery → Preview → name → new course
Pull changes: Alert on Content → Settings → Template → Review sheet
