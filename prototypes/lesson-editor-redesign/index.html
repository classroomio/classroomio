Lesson editor redesign

A unified content canvas replaces the current Video / Note / Slide / Document / Settings tab strip. This is a clickable prototype, not shipped code — it reuses ClassroomIO's real design tokens and component recipes (@cio/ui, app-theme.css) so it reads as a natural evolution of the current dashboard, not a new visual identity. Every page below is interactive: try the Edit/Preview toggle, open Settings, and add content.

What this prototype deliberately does not do

No Notion-style blocks, no drag-and-drop between content types, no new content types or settings, no public-renderer parity, no persistent split editor/preview, and no changes to the course-level sidebar or header — all out of scope per the PRD.
