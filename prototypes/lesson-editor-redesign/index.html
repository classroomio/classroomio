What are Props?

Props (short for properties) are how React components receive data from their parent. They're read-only — a component should never modify the props it receives.

  • Passed like HTML attributes: <Avatar name="Ada" />
  • Read inside the component via props.name, or by destructuring
  • Flow in one direction: parent → child

In the next lesson we'll compare props to state — the other half of how React components hold onto data.
