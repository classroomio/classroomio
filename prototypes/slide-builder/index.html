Slide Builder

A native slide deck teachers author, theme, present and export inside ClassroomIO — no round trip to Google Slides or Canva. Slides are structured data, so the assistant and MCP can write them, and the platform can measure them. The engineering PRD lives at prd/slide-builder/README.md.

Key product decisions baked into these prototypes:
· The Slide tab has two modes — embed an external deck, or build a native one. Both persist; slideMode decides what renders.
· Decks are an org-level library with a nullable lesson link, so one deck can serve many lessons.
· A slide is layout slots plus a free-position escape hatch. Slots own geometry; free blocks declare an explicit box.
· Overflow is arithmetic, rejected at the API boundary — neither a teacher nor an agent can save a cropped slide.
· Themes are token sets carrying no content, with one seeded from the organisation's brand.
· Heavy AI tools run as durable jobs, not inline in chat — cancellable, resumable, with progress.
· Deck content is structured jsonb rendered by components, never HTML through the lesson sanitizer.
· Exports are PDF and PPTX in v1, and the dialog is honest that PPTX slides arrive as images.
