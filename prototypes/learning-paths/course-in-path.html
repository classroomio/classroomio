Handling events

In React you respond to user interaction by passing event handlers as props to elements. Handlers are regular functions, and React normalizes the underlying browser event for you.

What you'll learn

  • Attaching onClick, onChange, and onSubmit handlers
  • Reading values from the synthetic event object
  • Updating state in response to an event

By the end of this lesson you'll wire up a small form that updates the screen as the user types — the foundation for everything interactive you'll build in this path.
