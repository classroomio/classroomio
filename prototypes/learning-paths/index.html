Learning Paths

A learning path is an ordered bundle of courses sold and taken as one: courses unlock sequentially (lessons + exercises complete → next course), one bundle price with savings, and an optional path certificate at the end. Built on the real packages/ui tokens. The engineering PRD lives at prd/learning-paths/README.md.

Every page has a theme toggle and cross-links so you can click through each journey end to end.

Key product decisions baked into these prototypes:
· Learning paths are a new entity (separate from Programs) — learning_path, learning_path_course (ordered), learning_path_member.
· Self-enrollment with bundle pricing from the public site; the price shows savings vs summed course prices.
· A course unlocks when the previous course's lessons AND exercises are complete; sequential unlocking is a per-path toggle.
· Path certificate is a teacher toggle with its own tab; visitor access to the syllabus is teacher-configurable.
· Public pages mirror the "minimal" org-landing theme; app pages mirror packages/ui (shadcn-svelte, Geist, OKLCH tokens).
