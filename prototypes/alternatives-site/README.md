# ClassroomIO alternatives website prototype

A high-fidelity, multi-page prototype of the competitor alternative landing pages: one alternatives hub, nine competitor pages and the supporting pages the buttons point to. It is plain HTML, CSS and vanilla JavaScript with no backend.

This is the visual prototype. The SEO strategy lives in Notion ("ClassroomIO SEO and Content Strategy"). The internal review dashboard from the same research is in `../seo-alternatives/`.

## Run it

Open the folder over a local server so fonts and relative links behave like a real site:

```bash
cd prototypes/alternatives-site
python3 -m http.server 8792
```

Then visit `http://127.0.0.1:8792/alternatives/index.html`. Opening `index.html` directly from disk also works in a normal browser.

Every page shares one navigation bar, footer and stylesheet. The footer links to all nine alternatives. Navigation menus open on click, the mobile menu opens from the hamburger, and FAQ items are accordions.

### Competitor page sections

Navigation, hero, problem and opportunity, introducing ClassroomIO, features and benefits, product showcase, comparison table, who ClassroomIO is best for (including when the competitor remains the better fit), FAQ, related guides, final CTA, footer.

Each page has its own headline angle, problem framing, feature selection, showcase mockup, comparison rows, fit lists and FAQ. The nine headlines use different structures on purpose.

## How it is built

Pages are generated by a small Node script so the head tags (title, meta description, FAQ structured data) are real HTML. Generated `.html` files are committed so the prototype opens without a build step.

```bash
node build.mjs
```

Needs Node 18 or later. Run it after editing anything in `src/`, then run `pnpm format:changed` from the repository root so the generated HTML matches the repo formatting.

```
build.mjs              writes every page
src/content/<slug>.mjs per-competitor website copy (edit this to change a page)
src/research/*.js      verified facts, comparison rows, sources and dates (from the research data)
src/site.mjs           plans, feature library, hub card copy
src/sections.mjs       competitor page sections
src/pages.mjs          hub and supporting pages
src/mockups.mjs        CSS-built product mockups
src/layout.mjs         head, navigation, footer
assets/css/site.css    one shared design system stylesheet
assets/js/site.js      menus, mobile nav, FAQ accordions, placeholder forms
assets/fonts           Geist and Geist Mono from the ClassroomIO design system
```

To change copy, edit the matching file in `src/content/` and run `node build.mjs`. To change a comparison row, a date or a source, edit `src/research/<slug>.js`. You can also edit the generated HTML directly for a quick tweak, but the next build overwrites it.

## Design

Follows the `classroomio-design` skill: Geist type, one blue (`#0233BD`) on warm paper and sand, notch cards, a gradient-wash hero, a dark showcase band and one blue CTA band per page. Mockups are built from HTML and CSS and use sample data for a made-up company. They are labelled as illustrative and are not screenshots of the product.

## Evidence rules in the copy

- ClassroomIO claims are limited to verified facts: Free (20 students, 500K AI credits), Early Adopter ($35 a month or $350 a year, 10,000 students, custom domain, branding, certificates, unlimited collaborators, API with limits and webhooks), Enterprise by quote (SSO with OIDC, unlimited students, up to four organizations), MCP on every plan.
- Not claimed: learning paths, SCORM or xAPI, native CRM connectors, a Zapier app, SOC 2, WCAG or HIPAA, migration tooling.
- Competitor facts carry the date checked. Customer feedback and hypotheses are labelled as such. Unverified comparison rows are marked.
- Competitor prices change. Re-check every figure on the publish date.
- Related guides link to three other alternatives pages. The comparison matrix lives in `src/matrix.mjs` and only shows rows where the competitor side is confirmed. The FAQ is shared in `src/faq.mjs`.
- No keyword volume or difficulty data is shown. None was available.

## Known limits

- Pages use `noindex` and no canonical tags because this is a prototype. Proposed URL slugs are in `src/research/<slug>.js` under `messaging.slug`.
- Forms on `get-started.html` and `demo.html` show a prototype message and send nothing.
- Product, Solutions and Resources are lightweight placeholders to give the navigation somewhere to go.
- Kajabi and Teachable pages target a mostly creator audience. Confirm search demand before building them for real.
