Course cohorts

Run one course for many batches. Each batch is an existing cohort; the course keeps one copy of its content while each cohort gets its own students, submissions, grades, attendance, newsfeed and schedule. Customers who duplicated a course per batch get a reversible Merge courses flow. Spec: prd/course-cohorts/README.md. Every screen has a state bar in the bottom-left.

Journeys

Merge copies: Courses banner → 1 Choose → 2 Review (click any chip) → 3 Cohorts → 4 Confirm → merging animation → result → open course
Teach many cohorts: People → cohort filter in the header → Submissions · Marks · Attendance · Analytics · News Feed (the filter follows you)
Per-cohort schedule: Live lesson → Lesson settings → Schedule by cohort → click a cohort (Course · Custom · None) · Exercise due dates
Run a new cohort: Course ⋯ → Duplicate → “Run a new cohort” → copy schedule, shift 14 days → new cohort’s Courses
Undo: Settings → Merge history → Undo preview → split animation → copies restored
Students: Cohort 6 student (own dates, drip locks, posts) · retake student with the Previous enrollment switch
