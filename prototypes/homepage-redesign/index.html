For developers

API, Webhooks, MCP.

Connect ClassroomIO to your own application, the tools your team already uses, and your AI client.

  • REST APILet your own application make authenticated requests to your academy, using an API key that belongs to your organization.
  • WebhooksGet a signed request at your own URL when something happens, like a student finishing a course. Failed deliveries are retried, and you can resend any of them.
  • MCP serverConnect Claude Code, Codex, Cursor, OpenCode, VS Code or Gemini CLI to create, edit and publish courses. It only gets the permissions you approve, and new courses start unpublished.
  • Self-hostingAGPL-3.0, on GitHub. Run it on your own infrastructure.
