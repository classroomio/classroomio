Discover Marketplace

Orgs publish course templates, image packs, docs and AI skills to classroomio.com/discover. Anyone can browse; org admins import free, one-time copies. Every listing is reviewed. Spec: prd/marketplace/README.md. Each screen has a state bar at the bottom for its other states.

Main journeys

Import:Discover→Listing→Log in→Pick org→Imported template→Rate
Publish:Marketplace (empty)→Publish dialog→Platform review→Listing published→Submit update
