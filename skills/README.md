# SEO and marketing skills

Workflows for ranking classroomio.com pages in Google and AI search, and for writing the copy on those pages. Each skill is a folder with a `SKILL.md`; open the file for the full instructions.

## Technical, research and on-page SEO

| Skill | Use it to |
| --- | --- |
| [seo-autopilot](seo-autopilot/SKILL.md) | Run daily repo SEO with persistent state in `seo/`: health checks, Page 2 to Page 1 pushes, competitor diffs, keyword map |
| [seo-roast](seo-roast/SKILL.md) | Run a revenue-first teardown, fix fatal blockers in code, and write `seo/roast-roadmap.md` |
| [blitz-seo](blitz-seo/SKILL.md) | Push one money page to page one for one keyword in a 30-day sprint |
| [ahrefs-research](ahrefs-research/SKILL.md) | Pull Ahrefs data for competitor page gaps, clean link targets, and Reddit pain mining |
| [dataforseo-serp](dataforseo-serp/SKILL.md) | Cluster keywords by live SERP overlap, find AI Overview citations, and lock search intent before writing |
| [proof-kb](proof-kb/SKILL.md) | Build a first-hand proof knowledge base in `seo/kb/` and upgrade pages with verifiable claims |
| [vs-and-alternatives](vs-and-alternatives/SKILL.md) | Ship `/vs/[competitor]`, `/[competitor]-alternative`, and `Best [category] for [persona]` pages |
| [internal-linking](internal-linking/SKILL.md) | Audit the link graph and route blog traffic into money pages |
| [domain-migration](domain-migration/SKILL.md) | Move domains or merge subdomains with verified 1-to-1 redirects |
| [seo-title-optimization](seo-title-optimization/SKILL.md) | Rewrite title tags and H1s against live SERP winners |
| [blog-refresher](blog-refresher/SKILL.md) | Refresh a slipping post using a SERP gap analysis |
| [block-ai-scrapers](block-ai-scrapers/SKILL.md) | Block scrapers and AI agents while keeping Googlebot indexing intact |
