# ICONOGRAPHY
- Custom **inline SVG line icons**, 24px grid, **1.8 stroke**, round caps/joins, `currentColor` or brand blue; arrows and chevrons at 2–2.2 stroke. Shown in 40px sand-100 tiles (10px radius) in menus. Captured as `Icon` (sparkle, users, palette, bolt, chat, arrowRight, chevronDown, search, lock, plus, close, github, play, sparkleFill).
- The 4-point **sparkle** is the AI motif (filled in blue/sky in prompts and agent pills).
- Integration logos are raster PNGs (e.g. `assets/images/integration-hubspot.png`).
- No icon font, no emoji. Closest CDN substitute if you need more glyphs: **Lucide** at stroke-width 1.8 — flag any use.
- Logo: `assets/logo-mark.svg` (three blue shapes: half-disc bar, circle, rounded L) + lowercase Geist 800 wordmark.
